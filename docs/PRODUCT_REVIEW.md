# Git Galaxy 사용자 관점 검토와 행성계 디오라마 방향

> 2026-09-26 · 실제 데스크톱·모바일 화면과 16개/100개 저장소 계정을 기준으로 검토

## 한 문장 판단

현재 프로토타입은 **한 번 멈춰 보게 하는 오픈소스 천문 시각화**로는 강하지만,
`내 계정을 찾는다 → 내 장소를 한눈에 이해한다 → 남에게 보여준다`는 제품 흐름은 약하다.

과학적인 분위기 자체가 문제는 아니다. 모든 저장소와 궤도를 같은 비중으로 한 화면에
보여 주려는 규칙이 사용자의 정체성과 조작성을 압도하는 것이 문제다.

## 채택한 제품 방향

세 배율은 서로 다른 시각 문법을 쓴다.

1. **우주 전체** — 지금의 데이터 기반 관측 지도. 규모와 관계를 보여 준다.
2. **계정 행성계** — 고정된 3/4 시점의 작은 게임 디오라마. 정체성과 공유를 담당한다.
3. **개별 저장소** — 기존의 광물 행성. 상세 데이터와 다음 항로를 담당한다.

계정 행성계는 실제 저장소를 삭제하거나 임의의 가짜 관계를 만들지 않는다. 대신 처음
보는 초상에서는 의미를 압축한다.

- 1–6개: 모든 저장소를 큰 행성으로 표시한다.
- 7개 이상: 대표 행성 최대 6개와 나머지 저장소 하나당 광점 하나인 바깥 벨트를 표시한다.
- 대표 행성은 첫 저장소, 최근 저장소, stars 신호, 언어 다양성을 함께 써서 결정한다.
- 향후 GitHub 인증을 붙이면 사용자가 대표 행성을 직접 고르게 한다.
- 전체 저장소 목록과 canonical 궤도는 정보 패널에서 계속 접근할 수 있다.

## 시각 언어

계정 화면의 방향은 **오픈소스 장난감 행성계**다.

- 행성은 실제 축척보다 크게 보이는 저다각형 도자기 구체다.
- 대표 행성 위에는 저장소의 성격을 기억하게 하는 랜드마크 1–3개를 둔다.
- 랜드마크는 관측소, 신호탑, 패키지 부두처럼 크게 단순화한 형태를 쓴다.
- 작은 숫자를 건물 수로 직접 바꾸지 않는다. 건물은 지표가 아니라 기억 장치다.
- 나머지 저장소는 벨트로 보이되, 광점 수는 실제 남은 저장소 수와 같다.
- 이름은 선택·근접 대상만 보여 주고 모든 라벨을 항상 켜 두지 않는다.

팔레트는 기존 세계와 연결한다.

## 진입과 공유 흐름

첫 화면은 시적인 문구만 두지 않고 결과를 설명한다.

> GitHub 아이디만 입력하면 당신의 행성계가 만들어집니다.  
> 로그인 없이 공개 저장소로 먼저 둘러볼 수 있습니다.

입력에는 `내 행성계 만들기` 버튼을 둔다. 계정을 가져오는 동안에는 `공개 저장소 N개를
관측 중`처럼 현재 상태를 말하고, 대표 행성을 먼저 보여 준 뒤 나머지를 채운다.

결과 화면의 기본 행동은 다음 세 개다.

- 대표 행성을 골라 저장소로 이동한다.
- 계정 행성계 주소를 복사한다.
- GitHub 원본을 연다.

로그인은 최초 진입에 요구하지 않는다. 향후 `내 시스템 꾸미기`에서만 GitHub 인증을
요청한다.

## 이번 구현 범위

- 계정 초상 모드: 대표 행성 최대 6개 + 실제 개수의 저장소 벨트
- 대표 행성의 큼지막한 3D 랜드마크
- 고정된 게임 디오라마 도착 구도
- 검색 실행 버튼과 명확한 진입 설명
- 계정 패널의 대표/전체 저장소 분리
- 행성계 주소 복사
- 모바일 하단 시트와 44px 터치 영역

이번 단계에서는 GitHub 로그인, 사용자의 대표 행성 편집, 서버 이미지 카드 생성은 넣지
않는다. 먼저 `내 장소가 한눈에 보이는가`를 검증한다.

## 구현 결과

2026-09-27 첫 구현에서 다음을 확인했다.

- 16개 저장소 계정과 100개 저장소 계정 모두 대표 행성 6개 구도를 유지한다.
- 나머지 저장소는 실제 개수만큼 바깥 벨트에 남는다.
- 대표 행성에는 데이터와 ID로 정해지는 관측소·패키지 부두·신호탑을 붙였다.
- 기존 9.5초였던 계정 검색 항해를 약 **5.7초**로 줄였다.
- 390×844 화면에서 가로 넘침이 없고, 주요 버튼 높이는 44px 이상이다.
- 기존 브라우저 흐름 테스트가 모두 통과했다.

사람 대상 검증은 아직 남았다. 다음 판단 기준은 렌더링 완성도가 아니라 처음 보는 사람이
설명 없이 대표 행성을 누르고, 결과 주소를 공유하는지다.
